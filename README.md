# PartitionPrimes1mod3
Partitions of primes that are 1 mod 3

<p>This site contains a number of files connected to the study of integer group determinants, especially for the abelian groups of order 27. See <i>The integer group determinants for the abelian  groups of order 27</i>, by Michael J. Mossinghoff and Chris Pinner, on the arXiv. It includes a list of primes 1 mod 3 up to 50000 partitioned into two types, as described in the article, and a further subdivision of the Type 2 primes that are 1 mod 9 into two types, called Type 3 and Tyupe 4. It also includes the corresponding databases of signatures for particular algebraic integers, as well as the full record of the computations that completed the proof of the main theorem of that paper.</p>

<p>A brief synopsis of each file appears here.</p>

| File | Description |
| :---- | :---- |
| Type1_50k.txt | List of all Type 1 primes 1 mod 3 less than 50000. |
| Type2_50k.txt | List of all Type 2 primes 1 mod 3 less than 50000. |
| Type3_50k.txt | List of all Type 3 primes 1 mod 9 less than 50000. |
| Type4_50k.txt | List of all Type 4 primes 1 mod 9 less than 50000. |
| Type1_SignaturesDB.txt | Signature database of vectors $(\epsilon_1, \epsilon_2, \epsilon_3, \epsilon_4, \epsilon_5)$ over {-1, 0, 1} for Type 1. |
| Type2_SignaturesDB.txt | Signature database of vectors $(\epsilon_1, \epsilon_2, \epsilon_3, \epsilon_4, \epsilon_5)$ over {-1, 0, 1} for Type 2. |
| Type3_SignaturesDB.txt | Signature database of vectors $(\epsilon_1, \epsilon_2, \epsilon_3, \epsilon_4, \epsilon_5, \epsilon_6, \epsilon_7)$ over {-1, 0, 1} for Type 3. |
| Type4_SignaturesDB.txt | Signature database of vectors $(\epsilon_1, \epsilon_2, \epsilon_3, \epsilon_4, \epsilon_5, \epsilon_6, \epsilon_7)$ over {-1, 0, 1} for Type 4. |
| Step1_Output.txt | Full output of the Step 1 calculation from the paper. |
| Step2_Output.txt | Full output of the Step 2 calculation from the paper. |
| Step3_Output.txt.gz | Full output of the Step 3 calculation from the paper (large file: 254MB uncompressed). |
